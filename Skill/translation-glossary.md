## Keep in English (already English or standard)
- All protocol names: BLE, BTC, Wi-Fi, LoRa, LTE, RFID, NFC, Zigbee, Z-Wave, Thread, GNSS, GPS, ADS-B, 5G NR, GSM, UWB
- All hardware: HackRF, RTL-SDR, bladeRF, USRP, Proxmark, Flipper, CatSniffer, etc.
- All modulations: GFSK, OFDM, CSS, O-QPSK, DSSS, BPSK, GMSK, etc.
- All crypto: AES, ECDH, Crypto1, A5/1, KASUMI, SNOW 3G, ZUC, etc.
- All command names: crackle, btlejack, rtl_433, rfcat, etc.
- All control IDs: RFSAM-*, BSAM-*
- All file paths and code
- CVSS, CVE, OWASP, CWE, FCC ID, etc.
